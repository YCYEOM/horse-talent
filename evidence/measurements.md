# 실측 — `npm run evidence` 가 만든다

손으로 적은 숫자가 아니다. `src/evidence/measure.ts` 가 지금 코드를 돌려서 낸 것이다.
`문서` 열은 `docs/GAME_SPEC.md` 의 주장이고, 어긋나면 **문서가 낡은 것**이다.

표본 — 경주 1,500회 · 한 판 1,200판. 시드 고정이라 재현된다.

## 1. 능력치 순위별 승률 — 경주는 시작 전에 정해져 있지 않다

무작위라면 전부 16.7% 다. 능력치가 밀되 결정하지는 않는다.

## 2. 스탯 5종이 결과를 움직이는가

기준은 속6·가6·체6·근3·안3 — 승률 41.1% · 3착 76.8% · 평균착순 2.35.

| 스탯 | 승률 | 3착 | 평균착순 |
|---|---|---|---|
| 속력 | +26.0%p | +14.5%p | -0.72 |
| 가속 | +19.0%p | +9.9%p | -0.51 |
| 체력 | +21.2%p | +12.1%p | -0.59 |
| 근성 | +13.2%p | +4.7%p | -0.28 |
| 안정 | -1.8%p | +4.4%p | -0.11 |

**안정만 승률이 안 오른다 — 설계대로다.** 컨디션 폭을 줄이면 요행 우승도 같이 깎이고,
대신 요행으로 무너지는 일이 더 줄어 3착이 오른다.

| 항목 | 문서 | 실측 | |
|---|---|---|---|
| 속력 승률 증가 | +26.0%p | +26.0%p | ✓ |
| 안정 승률 증가 | -1.8%p | -1.8%p | ✓ |
