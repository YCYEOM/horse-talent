## Problem

M5 는 **"빌드·테스트·증거가 재현된다"** 이다. 지금 재현 안 되는 것이 셋이다.

**1. 실측 수치가 사라졌다.** 이 게임의 밸런스 주장 전부 —
인기마 승률 34/25/20/13/9/0% · 파산 경험 8% · 스탯 5종 효과 · 국면별 최선의 수 —
가 `/tmp` 에 쓰고 지운 일회용 스크립트에서 나왔다. **문서에 숫자만 남고 만드는 법이 없다.**
`playSession`(그럴듯한 플레이어 모형)은 심지어 **검사 파일 안에** 있어서 밖에서 못 부른다.

**2. 증거 폴더가 비어 있다.** `evidence/` 에 README 하나.
빌드 산출물도, 검사 결과도, 화면도 없다.

**3. AI 사용 기록이 비어 있다.** `docs/submission/ai-use-log.yaml` 이 `entries: []` 다.
`records/HT-00*.json` 에 다 있는데 제출 형식으로 안 옮겼다.

그리고 M4 에서 **사람 판정 둘이 열린 채** 넘어왔다 — 유리 카드 대비 · 받아들이기로 한 넷.

## What we are shipping

### 1. `npm run evidence` — 한 명령

빌드 → 검사 → 실측 → 화면 순으로 돌고 `evidence/` 에 결과를 남긴다.
**중간에 뭐가 실패하면 거기서 멈추고 그 사실을 남긴다** — 반쯤 성공한 증거가 제일 나쁘다.

### 2. 실측을 코드로 되살린다

- `playSession` 을 `src/session.test.ts` 에서 **`src/systems/policy.ts`** 로 옮긴다.
  검사와 증거 스크립트가 **같은 모형**을 쓴다. 지금은 검사만 쓸 수 있다.
- `src/evidence/measure.ts` — 문서에 적힌 수치를 전부 다시 낸다.
  결과는 `evidence/measurements.md`. **숫자가 문서와 다르면 그것이 발견이다.**

### 3. 화면 증거

`?go=<phase>` · `?t=<초>` 는 이미 있다. `scripts/shots.mjs` 로 6장을 찍어
`evidence/screens/` 에 넣는다. **크롬이 없으면 건너뛰고 그렇게 적는다** — 조용히 빠지면 안 된다.

### 4. 라이선스 목록

런타임 의존성 **0개** · 외부 에셋 **0개**(트랙 스프라이트는 되돌렸다).
개발 의존성 넷(bass-platform · typescript · vite · vitest)만 적는다.
`evidence/licenses.md`.

### 5. AI 사용 기록

`records/HT-001..007.json` 에서 `docs/submission/ai-use-log.yaml` 로 옮긴다.
**손으로 다시 쓰지 않는다** — 스크립트로 뽑아야 다음 작업에서도 따라온다.

### 6. 남은 사람 판정 둘

유리 카드 대비 · 받아들이기로 한 넷. **화면과 함께 다시 묻는다** —
M4 에서는 글로만 물어서 답이 안 나왔다.

## What we are not shipping

- **새 시스템 · 승식 · 스탯 · 페이즈** — M4 동결은 그대로다
- 규칙·값 변경. **측정 결과가 문서와 달라도 이번엔 기록만 한다**
- 사운드 · 저장 · 아트 방향
- 배포(GitHub Pages). 저장소가 비공개라 **가능한지부터 확인하고 사람에게 묻는다**

## Facts

- 런타임 의존성 0. `dependencies: {}` — 캔버스와 표준 라이브러리뿐이다.
- `playSession` 이 `src/session.test.ts:32` 에 있고 `export` 는 붙어 있지만
  **vitest 밖에서 import 하면 터진다**(`vi` 훅 때문). 그래서 증거 스크립트가 못 쓴다.
- 검사 148개 / 7파일 / 약 35초. 관중 몬테카를로가 대부분이다.
- `evidence/` 에 README 1개, `docs/submission/ai-use-log.yaml` 은 `entries: []`.
- `nan/trace.yaml` 은 자리표시자(THEME-001 → … → EVD-001)뿐이고 **실제 파일을 안 가리킨다.**
- 저장소는 **비공개**다 (github.com/YCYEOM/horse-talent).

## Decisions

- **증거는 만들어지는 것이지 적는 것이 아니다.** 손으로 적은 수치는 다음 변경에서 거짓이 된다.
- **실패하면 멈춘다.** 반쯤 채워진 `evidence/` 는 없는 것보다 나쁘다 — 재현됐다고 읽힌다.
- **모형을 한 곳에 둔다.** 검사와 증거가 다른 플레이어 모형을 쓰면 두 숫자가 갈린다.
- **측정이 문서를 반박하면 문서를 고치지 말고 먼저 기록한다.** M5 는 값 조정 단계가 아니다.

## Assumptions

- `playSession` 을 옮겨도 검사 결과가 안 바뀐다고 가정했다. **바뀌면 그게 발견이다.**
- 문서의 수치가 지금 코드에서 재현된다고 가정했다. **12R 고정 뒤 다시 안 잰 것이 있다.**
- 크롬 헤드리스가 CI 없이 로컬에서만 돈다고 가정했다.
