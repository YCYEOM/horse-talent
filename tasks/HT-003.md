> **사후 작성 명세다.** 구현이 먼저 갔고 코드 주석과 DESIGN.md 가 `HT-003` 을
> 가리키는데 명세가 없었다. 참조를 지우는 대신 명세를 쓴다 —
> 네 변경이 한 플레이 세션에서 나온 한 덩어리라 하나의 작업으로 남기는 것이 정확하다.

## Problem

플레이 지적 셋 + 그 과정에서 발견한 버그 하나.

1. **경주가 1착에서 끊겼다.** 승식 7종 중 넷이 3착까지 보는데 화면이 1착 통과에서
   끝났다 — **판정 근거를 안 보여주는 화면**이었다. 기능 결함이다.
2. **도움말 버튼이 불필요했다.** 승식을 고르면 아래에 이미 설명이 나오는데
   버튼을 또 뒀다.
3. **디자인이 낡았다.** 나무 패널 + 크림색 버튼 + 3px 갈색 외곽선.
   참조로 media.io 를 받았다.
4. **강화 결과가 연출 전에 새어나왔다.** 1.65초 연출이 통째로 무의미했다.

## What we are shipping

### 1. 3착까지 들어오는 것을 본다

- `runRace` 가 결승선 뒤로 `EXTRA` 10구간을 더 돈다.
- **결승선 = 1착이 `SEGMENTS`(10) 구간에 끊는 지점.** 나머지는 그 뒤에 들어온다.
- `Result.finish` — 각 말이 선을 끊는 시각(구간 단위, 구간 사이 보간).
- 화면은 **3착이 들어온 뒤 0.8초**에 끝난다. 들어온 말에 착순 배지가 붙는다
  (3착까지 금색, 나머지 회색).
- **관중 시뮬은 `quick` 모드로 연장을 건너뛴다** — 배당 한 번에 400판을 돌리는데
  거기까지 연장하면 검사가 몇 배 느려진다. 관중은 1착만 알면 된다.

### 2. 도움말 버튼과 오버레이를 지운다

**눌러야 보이는 설명은 안 눌러본 사람에게 없는 것과 같다.**
대신 항상 보이는 설명 카드에 **예시까지** 넣는다 —
`예) 4→2→6 이면 4,2 또는 2,4 적중`.

호버 미리보기는 **남긴다.** 그건 설명 은닉이 아니라 고르지 않고 둘러보는 수단이다.

### 3. 아트 2차 — 유리 카드 + 그라데이션

| | 1차 | 2차 |
|---|---|---|
| 바탕 | 단색 남보라 | 위아래 옅은 그라데이션 |
| 면 | 크림색 패널 + 3px 갈색 외곽선 | **유리 카드** — 흰 면 4~7% + 1px 테두리 |
| 강조 | 금색 버튼 | **보라→청록 그라데이션, 주 동작 하나에만** |
| 라운드 | 9~10 | 14~20 |

`card()` 와 `accentGrad()` 를 토큰에 넣어 **씬이 색을 조립하지 않게** 한다.
버튼은 셋뿐이다 — 기본(유리) · 선택됨 · 주 동작(그라데이션).

**캐릭터는 안 바꾼다.** 낡아 보인 것은 UI 껍데기였지 말이 아니다.

### 4. 강화 결과 누출 수정

`forge()` 는 누르는 순간 엔진 상태를 바꾼다(결정성 때문에 그래야 한다).
그런데 화면이 그 값을 그대로 읽어 **단계 숫자 · 막대 · 다음 비용 · 확률 표시**가
전부 답을 말하고 있었다.

`revealLevel(actual, from, t)` 를 **순수 함수로** 빼서 판정 시각(`REVEAL` = 1.35s)
전까지 옛 값을 돌려준다. 렌더 안에 묻어두면 이런 종류는 영영 검사가 안 된다.

## Facts

- `Result` 에 `finish: Record<number, number>` 가 추가된다. 기존 `order`·`splits` 는 그대로다.
- `splits.progress` 의 정규화 기준이 **최대 누적**에서 **1착의 결승 시점 누적**으로 바뀐다.
  1.0 이 결승선이고 뒤 말들은 1.0 을 넘는다.
- 토큰이 통째로 바뀐다 — `C.panel`·`C.wood`·`C.woodDk`·`C.inkSoft`·`C.sky`·`C.turfDk` 삭제,
  `C.bg0`·`C.bg1`·`C.card`·`C.accent0`·`C.accent1`·`C.hoof` 추가.
- `bass design check` 의 하드코딩 hex 검사가 이 교체를 강제한다.

## Decisions

- **3착까지 도는 것이 기본값이다.** 스킵은 언제든 되지만 기본이 1착 컷이면
  판정 근거를 못 본 사람이 생긴다.
- **`revealLevel` 을 순수 함수로 뺀다.** 검사 가능성이 곧 재발 방지다.
- **`REVEAL` 상수 하나로 바늘과 숫자를 묶는다.** 둘이 어긋나면 또 샌다.
- **그라데이션은 주 동작 하나에만.** 여러 개면 무엇이 주인지 사라진다.
- **도움말 버튼을 지우되 호버는 남긴다.** 둘의 역할이 다르다.

## Assumptions

- 3착 뒤 0.8초가 "봤다"와 "지루하다" 사이라고 가정했다. 실측 없다.
- 유리 카드 대비(면 4~7%)가 이 바탕에서 충분히 읽힌다고 가정했다.
- media.io 계열 문법이 사용자가 말한 "현대식"과 같다고 가정했다.
  **취향 영역이라 사람이 봐야 안다.**

## Rollback
